# puter-cli

> **⚠️ This package has been renamed to [`@heyputer/shell`](https://www.npmjs.com/package/@heyputer/shell).**

This package is no longer maintained. Please migrate:

    npm uninstall -g puter-cli
    npm install -g @heyputer/shell

The `puter` command has been replaced by `puter-sh` (or the shorter `psh`).

**Looking for the deploy/dev tool?** That's a different package: [`@heyputer/cli`](https://www.npmjs.com/package/@heyputer/cli).
